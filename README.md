## Висновки  

В процесі виконання роботи було виконано кілька важливих етапів, спрямованих на оптимізацію продуктивності MongoDB, налаштування реплікації та шардінгу, а також використання MongoDB для обробки великих обсягів даних у поєднанні з інструментами Python та Machine Learning.  

Оптимізація продуктивності запитів: Завдяки використанню індексів вдалося значно зменшити час виконання пошукових запитів. Без індексів виконання запиту займало значний час, в той час як після створення індексу на полі name час запиту зменшився в кілька разів. Це демонструє важливість використання індексів для підвищення швидкості роботи з базою даних.  

Налаштування реплікації: Реалізація реплікаційного набору MongoDB забезпечила високу доступність даних. При записі на Primary, дані були доступні на Secondary-вузлах. Відключення Primary не призвело до втрати даних, оскільки один із Secondary автоматично став Primary, що підтверджує ефективність реплікації для забезпечення безперервності роботи.  

Реалізація шардінгу: Запуск двох екземплярів MongoDB у режимі шардів та додавання їх через MongoDB Shell продемонструвало можливості горизонтального масштабування. Це дозволяє MongoDB обробляти більші обсяги даних і підтримувати високу продуктивність, навіть при великому навантаженні.  

Таким чином, оптимізація запитів за допомогою індексів, налаштування реплікації для забезпечення доступності даних, а також шардінг для горизонтального масштабування є важливими інструментами для підвищення продуктивності і ефективності MongoDB в умовах великих обсягів даних.
