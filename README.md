# Data-base-informationalS

__Тема__: Робота з Redis  

__Мета__: Закріпити розуміння роботи Redis та навчитися використовувати його основні можливості.
  
---

Дана робота буде виконана за допомогою docker, для того щоб не налаштовувати середовище, також буде показано більше команд ніж вимагається в завданні лабораторної роботи. Файл .py з виконаням додаткового завдання доданий до репозиторію окремим файлом.

### Висновки:  

У ході виконання лабораторної роботи було розглянуто основні можливості Redis, зокрема роботу з рядками, структурами даних та тимчасовими ключами. Було досліджено та протестовано команди SET, GET, INCR для збереження та оновлення значень, а також механізм роботи лічильника. Окрему увагу приділено різним структурам даних, таким як списки (List), множини (Set), хеші (Hash) та відсортовані множини (Sorted Set), де було практично застосовано відповідні команди LPUSH, LRANGE, SADD, SMEMBERS, HSET, HGET, ZADD та ZREVRANGE. Крім того, було вивчено механізм TTL та створення ключів із встановленим часом життя, що дозволяє автоматично очищати застарілі дані. Для закріплення матеріалу розроблено міні-програму на Python, яка підключається до Redis, виконує збільшення лічильника, зчитує список задач та взаємодіє з базою даних. Перевірка коректності виконання команд здійснювалася через Redis-cli та власний код. У результаті виконано всі поставлені завдання, а також додаткові експерименти, що дозволили поглибити розуміння роботи Redis і його можливостей.
